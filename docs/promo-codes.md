# პრომო კოდები

ადმინი → მენიუ „პრომო კოდები“ (მხოლოდ ადმინი).

## როგორ მუშაობს

- **კოდი**: ლათინური ასოები/ციფრები, `-` ან `_`, 2–30 სიმბოლო (მაგ. `WEB10`). დიდ/პატარა ასოს მნიშვნელობა არ აქვს.
- **ფასდაკლება**: მთელი %, 1–90.
- **ვადა** (არასავალდებულო): მითითებული დღის ჩათვლით (23:59-მდე).
- **მოქმედებს**: „ყველა პროდუქტზე“ ან „არჩეულ პროდუქტებზე“ (ძებნით ირჩევა ერთი ან რამდენიმე; ვარიანტიან პროდუქტზე — ყველა ვარიანტზე). ინახება `productIds`-ში; ცარიელი სია = ყველა პროდუქტი.
- ჩართვა/გამორთვა, რედაქტირება (% და ვადა), წაშლა. წაშლა უკვე გაფორმებულ შეკვეთებს არ ეხება.
- „გამოყენებულია N-ჯერ“ = ამ კოდით გაფორმებული შეკვეთები, გაუქმებულის გარეშე.

## checkout

- მყიდველი წერს კოდს ველში „პრომო კოდი“ → „გამოყენება“ (ka/en/ru).
- ფასდაკლება მოქმედებს მხოლოდ **კოდის პროდუქტებზე** (ან ყველაზე) და მხოლოდ **სრულფასიანზე**; უკვე ფასდაკლებულზე (salePrice ან ძველი originalPrice) არ მოქმედებს. checkout-ზე შესაბამის პროდუქტთან ჩანს ნიშანი „CODE -X%“. მიტანაზე არ ვრცელდება.
- თუ კალათაში კოდის პროდუქტი არ არის: „კოდი თქვენი კალათის პროდუქტებზე არ მოქმედებს“.
- მაგალითი: LUNCH15 (15%) მხოლოდ ლანჩბოქსზე; კალათა ლანჩბოქსი 20×2 + ჭიქა 15 + ფასდაკლებული თეფში 25 → ფასდაკლება 15% × 40 = 6₾; ჯამი 80 - 6 + 5 = 79₾.
- `totalAmount = subtotal - promoDiscount + shippingCost`. ერთი და იგივე ფუნქციები (`src/utils/promo.ts → buildPromoLines + computePromoDiscount`) ითვლის ეკრანზეც და `createOrder`-შიც: ეკრანი = Flitt-ის თანხა = შეკვეთის totalAmount.
- `createOrder` კოდს თავიდან ამოწმებს. თუ კოდი გამოირთო/ვადა გაუვიდა ან ფასდაკლება ეკრანს არ ემთხვევა — შეკვეთა არ იქმნება (ტრანზაქციამდე, მარაგი ხელუხლებელია) და მყიდველი ხედავს შეტყობინებას.
- კოდის გარეშე შეკვეთა ზუსტად ისე მუშაობს, როგორც ადრე.

## სად ჩანს

შეკვეთის დეტალები (ადმინი), შეკვეთის წარმატების გვერდი, Excel (სვეტები „პრომო კოდი“, „ფასდაკლება“; „სულ თანხა“ ფასდაკლებით), ადმინის მეილი. მიტანის თანხის შეცვლისას ფასდაკლება რჩება.

## უსაფრთხოება (Firestore rules, ბლოკი 13)

`promoCodes/{code}`: `get` — ყველას (მხოლოდ ზუსტად ჩაწერილი კოდი); `list`, ჩაწერა — მხოლოდ ადმინს. ასე კოდების სია საიტიდან ჩამოსათვლელი არ არის.

## Meta Pixel

`AddToCart` (კალათაში დამატება), `InitiateCheckout` (checkout-ის გახსნა), `Purchase` (წარმატების გვერდზე: ნაღდზე მაშინვე, ბარათზე მხოლოდ გადახდის შემდეგ; ერთხელ თითო შეკვეთაზე, `eventID` = შეკვეთის ნომერი). `content_ids` = productCode (იგივე, რაც Google Merchant feed-ში).
